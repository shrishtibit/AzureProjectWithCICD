# Building an End to End Data Engineering Solution with Azure  
End-to-end Azure Data Engineering project using the latest technologies like Azure Data Factory, Databricks, PySpark, Azure Data Lake, and CI/CD with Azure DevOps.  
Dataset - Paris 2024 Olympics Summer games (https://www.kaggle.com/datasets/piterfm/paris-2024-olympic-summer-games)   

 ⚙️ Integrated Azure DevOps with ADF for end-to-end CI/CD pipeline automation.  
 🔗 Built dynamic ingestion pipelines in ADF to pull data from GitHub to ADLS.  
 🎯 Parameterized pipeline URLs for reusability and scalability.  
 🗂️ Set up Unity Catalog with external locations for Bronze, Silver, and Gold layers.  
 🧹 Performed data cleaning: null checks, type casting, deduplication, and formatting.  
 🔁 Applied window functions for complex aggregations and ordering.  
 🪵 Saved transformed data in Delta format in the Silver zone for versioning.  
 ⚡ Built Delta Live Tables (DLT) pipeline for real-time streaming to the Gold layer.  
 ✅ Ensured reliable, curated, and version-controlled datasets in the Gold zone.  
 🚀 Strengthened hands-on knowledge of modern Azure data engineering workflows.  
 🎷Gained practical experience in data lake architecture, governance, and streaming.
